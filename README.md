# 가볍게 읽는 시리즈 (Light Reads)

어려운 기술 주제를 실습 없이 개념 중심으로, 편하게 읽히도록 정리한 HTML 책 모음입니다.

**바로 읽기:** https://jcdororo.github.io/light-reads/

## 책 목록

| 번호 | 책 | 링크 |
|---|---|---|
| 01 | 가볍게 읽는 Graph Studio | [graph-studio/](https://jcdororo.github.io/light-reads/graph-studio/) |

## 구성

```
light-reads/
├── index.html          시리즈 표지 (책 목록)
├── graph-studio/
│   └── index.html      가볍게 읽는 Graph Studio
└── README.md
```

- 책 하나는 폴더 하나이며, 폴더 안의 `index.html` 한 파일에 CSS와 스크립트가 모두 들어 있습니다.
- 새 책을 추가할 때는 영어 폴더 이름(예: `kubernetes/`)으로 폴더를 만들고, 표지 `index.html`의 책 목록과 이 README의 표에 한 줄씩 더합니다.
- GitHub Pages(`main` 브랜치, 루트)로 배포합니다.
